# Issue tracker

Issues live as local Markdown files under `.scratch/<feature-slug>/`: the spec as `spec.md`, one ticket per file in `issues/<NN>-<slug>.md`, numbered in dependency order. There is no GitHub repository yet; when one exists, move the open tickets to GitHub Issues and update this file.

Triage labels, written as the ticket's **Status** line: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.
